  БЫСТРАЯ ИНСТРУКЦИЯ: Настройка автообновления на Timeweb
═══════════════════════════════════════════════════════════════

📌 ШАГ 1: Откройте SSH консоль на Timeweb
   - Зайдите в панель управления Timeweb
   - Найдите "SSH доступ" или "Консоль"
   - Откройте консоль

📌 ШАГ 2: Скопируйте и вставьте эти команды по очереди:

   ┌─────────────────────────────────────────────────────────┐
   │ cd /root/udobnysklad                                    │
   └─────────────────────────────────────────────────────────┘

   Если папки нет, сначала выполните:
   
   ┌─────────────────────────────────────────────────────────┐
   │ cd /root                                                 │
   │ git clone https://github.com/Kladovki/udobnysklad.git    │
   │ cd udobnysklad                                          │
   └─────────────────────────────────────────────────────────┘

📌 ШАГ 3: Настройка автообновления (одна команда):

   ┌─────────────────────────────────────────────────────────┐
   │ chmod +x setup_auto_update.sh && ./setup_auto_update.sh │
   └─────────────────────────────────────────────────────────┘

   Эта команда автоматически:
   ✓ Создаст виртуальное окружение (если нужно)
   ✓ Установит зависимости
   ✓ Настроит автообновление
   ✓ Включит проверку каждые 5 минут

📌 ШАГ 4: Проверка (опционально):

   ┌─────────────────────────────────────────────────────────┐
   │ sudo systemctl status auto_update.timer                  │
   └─────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════
  ✅ ГОТОВО! Теперь код будет обновляться автоматически!

📝 ПОЛЕЗНЫЕ КОМАНДЫ:

   • Проверить статус:
     sudo systemctl status auto_update.timer

   • Посмотреть логи:
     sudo journalctl -u auto_update.service -f

   • Обновить вручную прямо сейчас:
     sudo systemctl start auto_update.service

   • Остановить автообновление:
     sudo systemctl stop auto_update.timer

   • Включить автообновление:
     sudo systemctl start auto_update.timer
